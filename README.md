# 化學物質大冒險 · 小三科學探險隊

給小三（小學三年級）學生閱讀的互動科學網頁，內容改寫自《有害物質科學常識：Survival from Toxic Chemicals》。

## 內容
11 個章節，包括：生活中的化學物質、有害物質進入身體的途徑、風險與暴露、新屋新車症候群、四大可疑成分、安全使用五守則、米奇的一天、急性中毒急救、生物濃縮與食物鏈、四個真實案例，以及 8 題小測驗。

## 互動元素
- 浴室尋寶（6 個熱點）
- 三條進入途徑卡片
- 風險天平滑桿
- 甲醛通風小遊戲
- 四大嫌疑犯翻卡
- 安全五招檢查表
- 一天時間軸
- 急救情境選擇
- 食物鏈疊疊樂
- 星星收集與測驗評分（localStorage 記錄進度）

## 使用
直接用瀏覽器開啟 `index.html`，無需任何建置工具或伺服器。
